■ 1. ロリポップへの設置手順
────────────────────────────────────────
1. ロリポップのユーザー専用ページにログインし、「ロリポップ！FTP」を開くか、
   FTPソフト（FileZilla等）を使用します。

2. 公開したいフォルダ（例：ルートディレクトリ または goldvision フォルダ）の中に、
   今回納品したファイル一式（index.phpなど全て）をアップロードしてください。
   
   ※「goldvision」フォルダごとアップロードした場合のURL例：
     http://your-domain.com/goldvision/

3. ブラウザでアクセスし、表示を確認してください。

────────────────────────────────────────
■ 2. 宛先メールアドレスの変更方法（★重要）
────────────────────────────────────────
お問い合わせフォームからのメール送信先は、初期設定では仮のアドレスになっています。
必ずご自身のメールアドレスに変更してください。

【変更ファイル】 config.php
【変更箇所】 8行目付近

// 変更前
define('ADMIN_EMAIL', 'info@example.com');

// 変更後（例）
define('ADMIN_EMAIL', 'nakao@goldvision.jp');

※送信元メールアドレス（FROM_EMAIL）も、ロリポップで作成したメールアドレスに変更すると
  迷惑メール判定されにくくなります。

■ 4. OGP画像（SNSシェア時の画像）の設定方法
────────────────────────────────────────
LINEやSNSでURLをシェアした際に表示される画像（OGP）の設定を行いました。
画像を表示させるには、以下の作業が必要です。

1. 表示させたい画像（横1200px × 縦630px 推奨）を用意する。
2. ファイル名を「ogp.jpg」にする。
3. `assets/img/` フォルダの中にアップロードする。

これで、URLをシェアした際にその画像が表示されるようになります。

■ 5. 送信テスト手順
────────────────────────────────────────
1. サイトのお問い合わせフォームにアクセスする。

5. 入力したメールアドレスに自動返信メールが届いているか確認。
